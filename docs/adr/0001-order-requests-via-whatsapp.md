# Order Requests go through a prefilled WhatsApp message; the site stores no orders

Visitors order Books by sending the institute a WhatsApp message that the Book List prefills via a `wa.me` link; the site has no cart, checkout, order collection or address form, and the institute confirms every Order Request by hand. We chose this so the site never collects personal data (name, address), which would otherwise require a PDPO personal information collection statement plus storage and retention handling — disproportionate for about ten books sold to a small audience. Don't add an on-site form or order storage without revisiting that trade-off.

## Considered Options

- **On-site form for name and address, then redirect to WhatsApp** — tidier messages, but it collects personal data and adds a step where visitors drop off.
- **Cart and checkout with stored orders** — out of proportion to the volume, and payment and fulfilment are already handled by hand.
